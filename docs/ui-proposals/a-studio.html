Studio: docked tool rail and inspector

Turn the keyboard-only HUD into a conventional design-app shell. Tools get a left rail, every setting that today lives in a key combo or a modal dialog gets a live control in a right inspector, and the two drawn HUD bars become a real status bar. Shortcuts stay exactly as they are.

Live mock: click tools, toggle guides, switch palettes. The inspector replaces the F1 overlay, the Reference settings dialog and the two HUD bars drawn by Renderer.DrawHud.

What changes

Added

  • Tool rail (Select, VP, Trace, Box, Subdivide, Ellipse, Pan) with shortcut badges.
  • Inspector: VP slots and density, guide toggles, camera readout, reference opacity, palette picker.
  • Status bar: contextual hint, selection, cursor in plane coordinates, zoom.

Removed / moved

  • Top and bottom HUD bars drawn inside the viewport.
  • Reference settings modal folds into the inspector.
  • F1 overlay stays, but is no longer the only way to learn the tools.

Build cost

  • MainWindow.axaml: Grid with rail, viewport, inspector, status bar.
  • World needs change notification (or a Changed event) so panels stay in sync with key presses.
  • Medium effort; no geometry changes.

Risks

  • Panels take ~310 px from the viewport; needs a collapse toggle (Tab).
  • Selftest renders the viewport alone, so HUD checks move to a separate headless window test.
