Chitin · UI overhaul

Three directions to review

Today the app is a menu bar over a full-window viewport, with two HUD bars drawn by the renderer and every feature behind a shortcut or the F1 overlay. Each proposal keeps all shortcuts and the drawing itself unchanged; they differ in how much chrome they add and where settings live.

OverviewA · StudioB · Canvas-firstC · Atelier

A · Studio

Tool rail, inspector, status bar. Familiar design-app shell; every setting gets a control.

B · Canvas-first

Full-bleed canvas, floating dock and chips, Ctrl+K command palette. Closest to the original.

C · Atelier

Paper-toned shell, layers panel, nine-point deck, rig picker. Built around the construction tools.

Recommendation

Start with B: its command table is a prerequisite for A and C anyway (one source for menus, help and shortcuts), it keeps the canvas whole, and it ships without touching geometry or the file format. Add C's layer visibility later if hiding boxes and ellipses turns out to matter in practice.
