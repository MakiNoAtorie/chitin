What changes

Added

  • Layers panel: reference, grid, trace lines, boxes, subdivisions, ellipses, cone; each hideable, with item counts.
  • Point deck: nine cards with colour, shortcut, density bar; empty slots shown as drop targets.
  • Rig picker in the top bar; presets and saved rigs in one list.
  • Light paper-toned chrome around the dark viewport, matching the atelier palette.

Removed / moved

  • Camera menu (now the rig picker), View menu toggles (now layer eyes).
  • HUD bars; horizon, FOV and zoom move to the top bar readout.

Build cost

  • Per-layer visibility in World and GuideBuilder: boxes, subdivisions, ellipses and trace lines each gain a visibility flag (saved in the project file).
  • Highest effort of the three; touches the render path and the project schema.

Risks

  • Schema change needs a version bump and a load test for old files.
  • Deck takes 112 px of height; it should collapse to a chip row on small windows.
